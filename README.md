# 流光下载 (FlowLight Download) - Windows 纯净专业版 v1.0.9

基于原安卓版《流光下载》核心架构与业务逻辑，深度结合 Windows 桌面生态，集成 **Aria2c 极速下载内核**、**百度/夸克网盘免客户端高速解析**、**边下边播**与**全网磁力/媒体嗅探**的纯净专业下载工具。

---

## 🌟 核心功能一览

1. **工业级极速下载内核 (Aria2c v1.37.0)**
   * 原生 64 位 Aria2 引擎，支持 HTTP/HTTPS 多线程（最大 32 线程分片加速）、BitTorrent、Magnet 磁力链。
   * **自动集成全球最佳 BT Trackers 列表**，几秒内发现海量 Peer，攻克冷门资源死种难题。

2. **☁️ 百度网盘与夸克网盘深度集成 (新增)**
   * **夸克网盘解析**：输入夸克分享链接（支持自动识别提取码），后台直接调用官方 PC 接口拉取目录树，勾选后自动获取高速直链并以 16/32 线程直推 Aria2 下载。
   * **百度网盘解析**：提取公开分享文件详情，支持验证码校验。
   * **Cookie 自动无缝共享**：在内置浏览器中登录个人夸克/百度网盘后，Electron 会话 Cookie 自动生效，无需手动复制复杂的认证 Header。
   * **油猴脚本 (Tampermonkey) RPC 直推**：支持配合各大网盘直链助手脚本，点击网页上的“RPC 导出”即可将任何超大原画文件秒级推入本软件下载！

3. **视频边下边播 (Play While Downloading)**
   * 采用前置/尾置分片优先顺序下载策略（`--bt-prioritize-piece=head,tail`）。
   * 内置流式 HTTP 206 (Partial Content) Range 响应服务器，视频缓冲少许即可在应用内无缝直接播放，无需等待全量下载完成。

4. **全网磁力资源聚合搜索**
   * 内置免翻多源磁力搜索引擎，直接在软件内键入关键词检索全网影视、动漫、系统镜像与开源资源。
   * 结果卡片展示资源大小、热度/做种数、发布时间，支持一键加入高速下载队列或一键复制磁力链接。

5. **网页智能媒体嗅探器 (Web Sniffer)**
   * 基于 Chromium (Electron) 底层网络请求拦截机制，支持 Cookie & Referer 自动穿透（解决网盘 403 防盗链报错）。
   * 在内置沙盒浏览器中访问任意视频网站，自动捕获底层流媒体（`.mp4`、`.m3u8`、`.flv`、`.webm` 等）及下载直链。

6. **纯净无扰设计**
   * **完全剔除原安卓端的注册/登录强制限制、手机号绑定、VIP 会员充值卡点、弹窗广告与公众号引流**。
